CHUKWU FAVOUR E. — PORTFOLIO WEBSITE

CONTENTS
- index.html: Home page
- about.html: Biography, education and skills
- projects.html: Three clearly labelled concept projects
- planner.html: Academic task planner (tasks saved in this browser)
- contact.html: Validated contact form that opens the visitor's email app
- css/style.css: Shared styling, responsive layout and animations
- js/script.js: Navigation, theme toggle, animations, planner and form validation
- images/profile.png and images/profile2.jpg: Your supplied photographs

HOW TO OPEN IN VS CODE (WINDOWS)
1. Extract the downloaded ZIP file first. Do not work from inside the ZIP preview.
2. In VS Code, choose File > Open Folder.
3. Select the extracted folder named favour-portfolio-ready and click Select Folder.
4. In the Explorer, click index.html.
5. To preview it, right-click index.html and choose Open with Live Server (if installed). If you do not have Live Server, open the extracted folder in File Explorer and double-click index.html to open it in your browser.
6. Save edits with Ctrl+S.

IMPORTANT
- Keep the css, js and images folders beside the HTML files.
- These projects are demonstration concepts, not claims of completed client work.
- The contact form validates fields and opens an email app; it does not send messages from a server.
- The planner stores tasks only in the current browser on this device.
- For publishing, upload the extracted project to GitHub and enable GitHub Pages, or use another static website host.
- The Google Fonts import requires internet access; the site has fallback fonts if offline.
